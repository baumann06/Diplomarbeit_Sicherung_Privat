# TimeTracker – Installation und Nutzung

Im `dist`-Ordner befindet sich die ausführbare Datei (`.exe`) für den TimeTracker.

## Installation

1. Den gesamten **TimeTracker**-Ordner herunterladen (nicht nur die `.exe`).
2. Den Ordner an einem gewünschten Ort auf deinem Rechner ablegen.

## Verknüpfung erstellen

1. Im **dist**-Ordner die Datei `TimeTracker.exe` suchen.
2. Rechtsklick auf die `.exe` → **Verknüpfung erstellen**.
3. Die erstellte Verknüpfung auf den Desktop verschieben.

Fertig – ab jetzt kannst du den TimeTracker bequem über das Desktop-Icon starten.
